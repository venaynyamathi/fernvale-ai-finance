# Close playbook

The month-end close as three Claude skills, saved to Claude so the desktop app can use them with the Fernvale MCP tools:

| Skill | Covers |
|---|---|
| [fernvale-month-end-close](fernvale-month-end-close.md) | Orchestrator: context, policies, materiality, the 12-step checklist, approvals, close package |
| [fernvale-close-reconciliations](fernvale-close-reconciliations.md) | Bank, Stripe clearing, corporate card, AR (cash application, aging, reserve), AP (duplicates, unrecorded liabilities) |
| [fernvale-close-entries](fernvale-close-entries.md) | CRM-to-billing bookings, deferred revenue waterfall, accruals, prepaids, depreciation, payroll, commissions, bonus, flux and budget review |

The playbooks describe standard close procedures only. They were written without reference to the specific errors planted in the data, so a run is a fair test.

**How to run:** in a new chat in the Claude desktop app (Fernvale tools connected), say "Run the October 2026 close for Fernvale." Review and approve each proposed entry. Afterwards, score the run against the answer key and refine the playbooks where it missed.

These files are the version-controlled copies. The skills themselves live in your Claude account.
